# Optional: voice-message transcription for HTML chat export.
#
# Only needed if you want voice messages to appear as text. Install with:
#     python -m pip install -r requirements-voice.txt
#
# `pilk` decodes WeChat's SILK v3 audio, which neither browsers nor ffmpeg
# can decode - that part is always local.
#
# Two cloud recognition engines (see OPERATIONS.md, 「语音消息」), plus a
# local fallback. Auto-selection prefers MiniMax, then DashScope:
#
#   MiniMax (asr-1.0): **zero extra dependencies** - a single multipart POST
#     built with stdlib urllib. Commercial-quality Chinese/Cantonese ASR,
#     seconds per clip, audio leaves the machine. Key: `minimaxApiKey`.
#
#   DashScope (paraformer-realtime-v2): needs `websockets` (below).
#     Commercial-quality ASR over a WebSocket protocol. Key: `dashscopeApiKey`.
#
#   Local fallback: `faster-whisper` on-device. Nothing leaves the machine, but
#     the small model gets dialects/Cantonese *confidently wrong* - fluent text
#     that says something never said. The model is fetched separately
#     (see OPERATIONS.md). Only opt into this explicitly (`--engine local`
#     or `--transcribe-voice`); it is slow and CPU-heavy.
#
# On an NVIDIA GPU, also install the CUDA runtime wheels the recognition
# library loads at runtime. Without them it falls back to CPU and is roughly
# 30x slower:
#     python -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
websockets>=12.0
pilk>=0.2.4
faster-whisper>=1.0.0
